# Using the IO helper class

Java 26 introduces a simpler way of reading from the console. The result of the previous pages ends up at the following approach:


```java
import java.util.Scanner;

public class ScannerExample {

    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in); // Create a Scanner object
        String line = scanner.nextLine();
    }
}
```

That particular piece of code, above, will read in the next line the user enters into the console.

## IO alternative

With the newly introduced `IO` class, we can simplify it to the code snippet below. I will also use the simplified main method.

```java
void main()
{
    String line = IO.readln();
}
```

The `readln()` method also allows you to create a "prompt" for the user, by passing in a `String` argument, like this:


```java
void main()
{
    String line = IO.readln("Please input text: ");
}
```

What shows in the console, is then:

```console
Please input text: hello there
```

Notice that the user input "hello there" is at the end of the prompt.

You are free to use whichever approach you prefer. The "old way" has a bit more flexibility, as it can read console input into different types, like String, double, int, etc. Whereas the new `IO` approach just reads a `String`, and you will have to manually convert it.
