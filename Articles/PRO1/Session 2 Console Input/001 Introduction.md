# Getting Input from the Console

Many applications require user input to function properly. Web sites have buttons, and text boxes, and check boxes, and so on.\
We will get to graphical user interfaces (GUIs) later, but for now we will focus on the console.

You already learned how to print text to the console.

In this article we will look at getting _input_ from the console.

## Deprecation disclaimer

This learning path shows the "old" way of reading from the console, using a `Scanner` object. This approach is more or less deprecated after Java 26, as they have simplified how to read from the console. I will keep it, though, as you may encounter this code in several examples, and should therefore know about it.

Page 5 will show the newer approach.
